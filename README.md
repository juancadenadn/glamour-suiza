## Cómo verlo localmente

Abre `index.html` en cualquier navegador (doble clic).

## Publicar gratis con GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube **todos** estos archivos a la raíz.
2. En el repo: **Settings → Pages**.
3. En *Source* elige la rama `main` y la carpeta `/ (root)`. Guarda.
4. En 1–2 minutos tu sitio estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
